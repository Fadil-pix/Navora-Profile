Alur Layanan

Dari Input Data ke ID Card Fisik

  1. Isi Data & Foto Mandiri

    Masukkan nama, jabatan, kontak WhatsApp, email, dan media sosial. Pratinjau kartu langsung mengikuti ketikanmu.

  2. Halaman Web & QR Code Langsung Terbuat

    Data tersimpan ke Firebase dan tautan profil serta QR Code unik langsung siap dibagikan atau diunduh.

  3. Notifikasi Admin, Cetak & Pembayaran

    Begitu QR Code tampil, admin mendapat notifikasi untuk mencetak kartu fisik, menerima pembayaran, dan menyerahkan kartu.

Kelengkapan

Yang Kamu Dapatkan

  • 01 Halaman web profil pribadi dengan tombol WhatsApp, Email, media sosial, dan ekspor kontak (.vcf).
  • 02 QR Code beresolusi tinggi (PNG) yang mengarah ke halaman profilmu.
  • 03 ID Card fisik cetak dari meja admin (Rp 25.000 saat pengambilan).
